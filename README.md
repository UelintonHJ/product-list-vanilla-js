# 🛒 [Product List - Vanilla JavaScript](https://product-list-vanilla-js.vercel.app/)

Aplicação web desenvolvida em **JavaScript puro (Vanilla JS)** que consome API pública para exibição de produtos, com foco em **boas práticas de front-end** e organização de código.

---

## ✨ Funcionalidades

- 📦 Listagem dinâmica de produtos
- 🔍 Busca com **debounce configurável**
- 🗂️ Filtro por categoria
- 📄 Paginação reutilizável com controle de páginas
- 🔗 Estado sincronizado com a URL (query params)
- ⏳ Skeleton loading durante carregamento
- 🧭 Navegação com histórico (back/forward do navegador)
- ⚠️ Tratamento de estados vazios e erro

---

## 🛠️ Tecnologias Utilizadas

- HTML5 semântico
- CSS3 (layout responsivo)
- JavaScript (ES6+)
- Fake Store API
- Vercel (deploy)

---

## 🔗 API Consumida

- **Fake Store API**
https://fakestoreapi.com/

## ▶️ Como rodar localmente

1. Clone o repositório:
```
git clone https://github.com/UelintonHJ/product-list-vanilla-js.git
```
2. Abra o arquivo index.html no navegador
*(não é necessário build ou servidor)*
